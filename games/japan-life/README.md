# 日本の暮らし（仮）／japan-life

日本を最初の舞台にする、独立した3D生活ゲーム。日本語で暮らし・料理・短い会話の自然さを本人が検証する。

2026-10-18：制作仕様と内容計画、Codexへの依頼文を準備済み。**ゲーム本体はまだ実装していません。起動できる配布物も未作成です。**

## 制作担当が読むもの

1. [SPEC.md](SPEC.md)：目的、町・住居・家具・時計・仕事・料理・会話・保存の規則。
2. [CONTENT_PLAN.md](CONTENT_PLAN.md)：初期の食材、料理6品、家具24種、服12点、住民60人の名簿と固有会話の種。
3. [RESEARCH.md](RESEARCH.md)：地域・料理と制作の出典、確認済みと未確認。
4. [CODEX_TASKS.md](CODEX_TASKS.md)：最初に貼る依頼文、M1～M4の制作順と合格条件。

日本を作ることは本人の決定。架空の港町「汐待町」、明石周辺を参考にすること、端末・技術・金額・時刻・人数は、制作に入れるよう作成者が補った変更可能な初期設定。実在の明石の街の忠実な再現ではない。

一つの町で、歩く、店へ入る、人と話す、買う、働く、料理する、部屋を整える暮らしを通す。住居は同時に一室。町並みと建物外装はプレイヤーが作り替えず、服・家具・壁飾りを変える。会話は固定の短い台詞と選択肢、外部生成AIとAPIキーは不要。

旧 games/english-errands/ は既存の別試作として保存し、コード・教材・セーブを上書きしない。

## 残る不足

完成用の街・人物・家具等の素材、全会話の返答と状況差分、読み・文化・日本語の確認、外国人初心者向けの案内言語と段階別教材、実装・ブラウザとスマホでの確認は未完了。制作を始めて検証するための仕様は準備したが、完成品や完成教材を用意した状態ではない。
