# M1・M2の短い実装計画

2026-10-18。正本：SPEC v0.1、CONTENT_PLAN、CODEX_TASKS。既存の英語試作は変更しない。

1. 内容データを分離し、取引・料理予約・勤務報酬・複数配達・月家賃・家具と転居・作品専用保存の状態管理を作る。境界と一度だけの処理を単体テストする。
2. Three.jsとViteで、4地区の三人称3D歩行、衝突とカメラ、入って歩ける店舗と3室、60人の人間モデル、PCとタッチの操作を作る。景観は独自の簡易モデルとし、完成美術とは称さない。
3. 選択会話・日本語の読みと再聴、買い物・勤務・スマホ配達・料理の手操作・家具配置と着替え・時計・保存のUIをつなぐ。UI中は移動と通常時計を止める。
4. ブラウザで実際の歩行と生活の一巡を確認し、画面証拠・テスト結果・M1/M2の達成と残件を保存する。単一HTMLとZIPを作り、内部パスを公開URLとせず、既存配信を保って入手方法を用意する。

技術案のJavaScript modules + Vite + Three.jsを採用。TypeScriptは必須ではない初期案のため、実行可能な状態管理の単体テストとブラウザ検証を優先してJavaScriptで実装する。依存は固定版とlockfileで保存する。ゲーム中の生成AI・APIキー・CDNは不要。
