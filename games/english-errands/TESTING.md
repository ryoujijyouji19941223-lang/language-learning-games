## 単一HTML版の追加確認

クラウド内のサーバーだけでは利用者がゲームを開けないため、`npm run build:standalone` で `dist/english-errands.html` を生成する手段を追加しました。画像24点・キツネ・CSS・実行コードを同梱し、追加ライブラリや外部ファイルを読み込みません。

- 単一HTMLの内容をループバックURLのHTTP応答として渡し、その後のネットワークを無効にした状態で、PC／360pxの計4件が合格。6件配達・途中再開・図鑑の全24画像・保存禁止時の起動を確認しました。通常版の18件とは別の追加確認です。
- 最初に `file://` で直接開く確認を4件試みましたが、管理Chromiumが `ERR_BLOCKED_BY_ADMINISTRATOR` で拒否しました。アプリのJavaScriptが実行される前の環境制限です。制限を解除せず、上記の内容確認へ切り替えました。実際のPCでダブルクリックして開く操作は未検証です。
- 単一版は分割ソースと同じコードから生成します。ソースを変更したら再生成してください。ダウンロード後に普通のPCブラウザで開くためのファイルであり、このチャット内にゲーム画面を公開するものではありません。
- `file://` の保存の可否や保存範囲はブラウザ依存です。保存不可の場合は通知して遊べ、JSONで退避できます。端末を変えるときはJSONを移します。

## 機能別の確認範囲

| 対象 | 確認したこと |
|---|---|
| 教材・画像 | 全12語・12依頼をSPECの表と照合。各2画像の実在と異なる内容、ブラウザ上で24画像の読込、全語が出題・候補になれること |
| 一連のプレイ | タイトル→導入→選択→荷札→受け渡し→6件の結果→次の組。3組18件を操作し全12語を届け、混合出題へ進む |
| 出題 | 先頭4件に組の4語、最後の2件は支援・誤答の多い語を優先、連続同語を避ける。混合は1語最大2回。正答位置・画像を固定しない（単体テストでは80シードで確認） |
| 後日の再使用 | 時刻を渡す単体テストで24時間の直前／経過後を分け、経過した語を混合の先頭へ優先。飾りを減らさない |
| 選択支援 | 誤選択2回で正しい名前とお手本を表示。全支援を使っても配達完了できる |
| 単語判定 | 大小文字、前後空白、NFKC／全角を許容。語の不足・途中空白・余分な語は拒否。`a cup`は品が合う旨と1語への訂正を案内 |
| 文転記 | 冠詞・語順・語を保持し、コンマ・末尾句点・大小文字・連続空白を許容。単語とは別記録。二重送信しない |
| 入力 | 物理Enter、画面Shift／Space／Backspace／Enter、全消去と再入力、お手本の次文字と相違箇所。画面キーだけでも単語と文の両方を完成 |
| IME | compositionイベント中のEnterが採点されず、確定後のEnterで採点される自動テスト。実機IMEは未確認 |
| 支援記録 | 英文・意味・お手本を閉じても使用履歴を保持。聞き取りは選択時点、綴りは荷札完成時点の状態を記録し、その後の復習表示で過去の成功を変えない |
| 成績 | 初回の対象選択、お手本なしの初回綴り、支援付き配達、任意の文転記を分けて集計。音声なし／失敗では聞き取り成功を付けない |
| 保存・再開 | 入力中にリロードして同じ途中入力を再開。各状態の保存・復元後も6件完了と報酬は1回だけ。履歴へ入力全文を残さない |
| 保存の例外 | 壊れたJSON・未対応版・別作品・不正な途中データを拒否。保存禁止でも支援付き配達まで操作できる |
| JSON移行・削除 | 実際のJSONダウンロード→作品の記録削除→ファイル読込→途中再開。不正ファイルでは現在の記録を保持。他作品のキーを削除しない |
| 設定・図鑑 | お気に入りの永続化、英語音声選択・速度0.8・音声オフ・停止、文字サイズ変更、図鑑の12語と音声ボタン |
| 非セキュアHTTP | crypto.randomUUIDが使えない場合でも開始できる単体テスト。認証用のIDには使用していない |

## 再実行と成果物

起動とコマンドは [README.md](README.md) 参照。`npm test` はサーバー・ネットワークなしで実行できます。ブラウザテストは未起動なら開発サーバーを立て、既に同ポートに起動済みならそれを使います。

`npm run test:browser` は `test-results/` に実行結果とPC／360pxのタイトル・入力画面の画像を出力します。失敗時はスクリーンショットとtraceを保存します。このフォルダはGit対象外です。
