# 次の国の生活・語学ゲーム：日本版の教訓と着手前の調査 v0.1

2026-10-20。日本・ギリシャ以外の独立作品を始めたいという本人の希望を受けた制作側の整理。次の国・言語・町はまだ選定していない。日本の完成を待つことを次国の調査の必須条件にしない。各作品の規模や遊びは独立して決める。

- ギリシャ版：mainは仕様準備の案内だが、[PR #1](https://github.com/ryoujijyouji19941223-lang/language-learning-games/pull/1)、ブランチclaude/greece-life-m1-m2（確認時HEAD e99ee50ab79fed3879355b7bf58732c2a3d2eb5f）に実装と検証記録あり。未マージ。地域の月別気象を使う天候、住民の家、段々の地形の改修が記録されている。ブラウザテスト等の作者の実行記録と、今回の担当の独立確認は分ける。
- 本担当が今回行ったのは文書・PRの確認と調査方法の整理。本作の実プレイ・新たな音声の実聴・ネイティブ校閲・学習者実験は行っていない。新国のゲーム本体も作っていない。
- 一つのmainの案内だけで制作全体の状態を判断しない。継続時は実際のブランチ・PR・進捗と配布物の対応を確認する。

全体の人数・家具・料理を勝手に減らす方針ではない。大きい完成目標を持ちながら、最初の確認単位を小さくする。日本やギリシャの数値を、別作品の一律の下限・完成条件へ自動移植しない。ギリシャ版に本人が指定した既存の規模条件は、この共通メモでは変更しない。

## 3. 最初に決める短い企画票

対象国／学ぶ言語と地域変種／モデルにする町・地区／時代／住みたい暮らし／主な端末／対象レベル／訳と説明に使う言語／最初の一仕事。

候補段階では2〜3地域を比較する。判断材料は、本人の関心、見た目と生活の違い、手で操作して楽しい仕事、必要な語の使い道、一次資料と普段の街の映像、使える素材、言葉を確認できる人や資料。資料の空白は「その文化にはない」と結論しない。次の国を本人の選択なしに確定しない。

## 4. 何を、どう調べるか

| 領域 | 集める資料・観察 | ゲームへ渡す成果 |
|---|---|---|
| 地理と景色 | 自治体・地図・地形資料、住宅地と市場を歩く映像。広域の立地と人の目線の両方 | 海・川・丘・山等の断面、道の幅・勾配・入口、遠景と目印、歩行経路 |
| 季節と天候 | 現地気象機関の月別資料、季節・時刻が分かる現地映像 | 月ごとの樹木・光・服・店先・天気。現実の開始月との対応。10月＝秋、冬＝積雪を全地域へ固定しない |
| 住居と普段の町 | 外観・室内の写真、生活者の紹介、店の営業案内・交通事業者の資料 | 家と店の配置、部屋の設備、通勤・買物・休む場所、普段の日と催しの日 |
| 文化と人 | 博物館・地域団体・催しの主催者、日常の服や趣味を写す資料 | 普段着、仕事着、特徴的な服、文化を匂わせる表現の混在。現実の観察と意図的な創作を区別 |
| 食と仕事 | 実際の店のメニュー、商品写真、作業・調理の映像、地域の食資料 | カウンターと器具の配置、容器・材料・工程、注文・確認・作り直し・提供の操作表 |
| 音と音楽 | 町・店・家庭の音の資料、地域の音楽資料 | 環境音、場所・時刻別BGMの方向。歌詞の有無、会話を聞く際の音量。音色差替えだけで地域性を判断しない |
| 言葉と文字 | 公的な語学資料、辞書、実際の看板・メニュー・会話資料、ネイティブ確認 | 短い自然な発話、読み、訳、音声原稿、文字入力と許容表記、丁寧さや数量の表し方 |
| 制作できる素材と操作 | モデル・表面素材・人物リグ・動作・音の入手元と条件、対象端末での小さな実験 | 素材一覧、必要な自作、描画の負荷、文字とカメラ、音声・入力の実機確認 |

観光公式の文章で地域の背景を押さえ、同じ町の日常の歩行映像・写真で配置や使い方を観察し、必要な項目を別資料と照合する。観光名所だけ、一本の旅行動画だけから国全体の暮らしを断定しない。資料にあるものを全部ゲームへ詰めず、歩いて意味が分かる配置と仕事へまとめる。

文化的な記号を排除する規則にはしない。本人が望むように、普通の服・個性的な街着・伝統を感じる衣装や景観を混ぜられる。その地域で観察できたもの、他地域から借りたもの、ゲームの遊び心として足したものを記録する。

## 5. 資料を仕様に変える記録票

調査はURLの一覧で終えず、次の列で一件ずつ残す。

| 項目 | 記入する内容 |
|---|---|
| 出典 | URL、作者・組織、資料の発表日・撮影日・閲覧日、地区、季節・時刻 |
| 実際に確認したこと | 本文の該当箇所、画像の対象、動画のタイムスタンプと観察。推測は別欄 |
| 採用するもの | 建物・道具・音・言葉・行動。一般の日常か、その場所・時期だけの例か |
| ゲーム用の調整 | 縮尺、時間、数量、創作の混在、省いた工程。変更理由 |
| 学習と操作 | プレイヤーが見聞きする言葉、意味、使う道具、結果の違い、再使用する場面 |
| 制作と証拠 | 作るモデル・素材と利用条件、データID、確認する画面や操作、未確認点 |

例（独自設計、特定国の事実ではない）：客が「ミルクは別で」と頼む→聞き直せる→別容器をトレーに添える→客に渡す。同じ語を買物や自宅料理でも再使用する。意味の違う注文を、同じ正解ボタンで終わらせない。

その言語で自然な注文の形、数量の読み、丁寧さ、語形、発音を改めて調べる。日本語の台詞の語順や文字の仕組みをそのまま翻訳する教材にしない。入力は文字・配列・合成記号・IME等の必要を対象端末で確かめ、タイプを全生活の必須条件にしない。

## 6. 調査から制作へ進む順

1. 言語・国・地域の候補を比較し、短い企画票を作る。複数作品の調査を並行してよい。
2. 選ばれた地域の「家→町の通り→店→仕事→帰宅」の一日を、写真・映像・言葉・音と結び付けて調べる。
3. 地形と配置、見た目、仕事の操作、言葉の目標、素材の見込みを一組の仕様へする。足りない資料を具体的な残件にする。
4. 一街区と一店舗で歩行・会話・注文・道具操作を動かす。実装画面で美術と視認性を確認し、本人の期待との差を記録する。
5. 音声・入力・描画速度・保存を対象端末で確かめ、別の客や店で同じ語を使えるかを任意の確認で見る。会話を聞いたことを理解済みと採点しない。
6. その結果で町・住民・仕事・季節を広げる。各作品に合う遊びを作り、日本の地形・桜・雪・路面電車・寺社や同じミニゲームを一括移植しない。

初期の到達点の提案：読める業種の看板、住戸に結び付く道、動く人物、同じ店の外観と内装、注文で行動が変わる一仕事、帰宅と保存。その国の雰囲気が実装画面で感じられ、初心者が支援を使って一つ用事を済ませられることを最初に確認する。試作単位であり完成作品の人数や教材数の上限ではない。

## 7. 共通に使えるものと、作品ごとに作るもの

共有候補：読みやすさの基準、セーブの検証、進捗と実行証拠、素材の記録、語と操作の対応表、学習と転記・再聴を分ける記録方法。コードは必要になった部品から再利用し、共通エンジンの完成を先行条件にしない。

作品ごとの対象：地理と季節、建築・交通・暮らし、文化の混ざり方、会話と文字・音、料理・仕事の工程、学習の入り口と順序、完成用美術。Farthest Frontierは日本版で本人が挙げた美術の目標で、全作品の同品質を確認済みという意味ではない。次の作品の見た目も実装画面で決める。

## 8. 方法の参考と今回の限界

- [Council of Europe：CEFRのaction-oriented approach](https://www.coe.int/en/web/common-european-framework-reference-languages/the-action-oriented-approach)：現実的な場面、学習者の主体性、受容・産出・相互行為等を組み合わせる学習設計の参考。本作の「言葉で用事を進める」という当てはめは独自案で、ゲーム単独の学習効果を証明する資料ではない。
- [WMO：Weather](https://wmo.int/themes/weather)：World Weather Information Serviceが各国気象機関の都市別の気象・気候情報を扱うことを確認。新国の季節調査の入口とし、具体的な町の服装・景色は現地資料でも確かめる。
- [Unicode LDML Part 7：Keyboards](https://unicode.org/reports/tr35/tr35-keyboards.html)：配列データや入力処理を調べる技術資料の入口。言語対応や音声をこれだけで全端末対応済みとしない。新作品へこの形式の完全実装を必須にしない。
- 本人の試遊指摘と日本版PLAYTEST_REDESIGN、ギリシャPR #1のREADME・PROGRESS・TESTING。今回、ギリシャの自動テストを独立に再実行していない。本人による美術の受入、ネイティブ校閲、対象端末の実聴、学習効果の検証は別に必要。

現時点は反省と調査の手順を保存した段階。次の国・言語・町の確定、新国の固有資料の本調査、完成素材の制作、新ゲームのコード実装は未実施。
