# フィンランドの暮らし（仮）／finland-life

## 現在の状態

2026-10-20、本人が次に学びたい言語として**フィンランド語**を選んだ。「Moi」とサルミアッキが手掛かり。日本・ギリシャとは独立した生活ゲームとして調査を始める。**企画・一次資料の初回確認まで。ゲーム本体、完成SPEC、美術、音楽、教材、音声は未制作。** 制作担当・説明言語・対象レベル・端末・最初の仕事・町はまだ確定していない。

既存作品の人数・料理数・地形・天候・祭り・入力規則をそのまま移さない。[次の国の調査手順](../../docs/NEXT_COUNTRY_RESEARCH.md)から進める。日本版の完成を調査の前提にはしない。日本やギリシャのコード・セーブを本作品の準備で変更しない。

## 本人の関心と、この作品への入口

- 町を歩き、買い物・仕事・料理・賃貸の部屋づくり・人との短い会話を楽しみながら、言葉と文化に触れたい。
- その土地らしい動物との、思いがけない出会い。顔だけでなく、歩く・座る・眠る・様子を見る動作。
- 会話に約10種類を再利用する人物画、動物の表情やしぐさは特に丁寧に。
- その国の童話や伝承を、季節の生活の出来事へ作り直せるのでは、という本人の提案。日本の笠地蔵や犬の話を名前だけ変えて移植する指定ではない。
- 普段は普通に暮らす。物語が毎日連続し、暮らしや語学試験を強制するゲームにしない。

## 物語への制作案（未採用）

### 家の近くにいるトントゥ

地域の伝承を追加確認した上で、家や共同サウナの世話をする→何かの気配→翌日ちょっとした変化に気付く、という短い出来事を考えられる。供え物と贈り物の因果、報酬、季節はまだ本作独自の案。FI04は特定のこの筋を収録する原話ではない。

サウナの掃除や用意を仕事にするなら、施設の実際の設備と手順を調べる。「日本のお地蔵さんのモデルを替える」だけにしない。信仰・民話・現代の施設の習慣も区別する。

### 森の小さな寄り道

Menninkäinen等を調べ、暗くなる時間の森で落とし物や短い謎をめぐる寄り道の候補にする。採用する昔話、季節、見た目、話し方は未確定。既存の絵本・キャラクターの外見を流用せず、本作独自の話と絵を作る。

いずれも「フィンランドなら必ずそうする」という現代生活の教材にはしない。サーミ等の特定文化の伝承を扱う場合は、言語・地域・担い手を確認し、全国共通へまとめない。

## 次に必要な調査

1. **住みたい地域の比較**：南部の都市／沿岸の小さな町／湖水地方等から、日常の通り・住宅・水辺・店・季節の光が見える2〜3地域を比較。まだゲームの町を勝手に決めない。北部を選ぶならその地域の資料も別に集める。
2. **動物と景色**：選んだ地域で会える動物・場所・時刻・季節を現地資料で確認。沿岸の町にサイマー湖のアザラシを一括配置したり、どの市街地にもトナカイを歩かせたりする方式にしない。猫・犬の普段のいる場所や、鳥・小動物も調べる。
3. **一日の生活と手で行う仕事**：家→通り→店→注文→道具操作→帰宅を、現地のメニュー・店舗設備・作業映像と対応付ける。料理・菓子・飲み物の候補は地域決定後に工程まで確認。
4. **言葉**：自然な口語と書き言葉、初心者が必要な語と句、語形の変わり方、音の長短、ä・ö等の文字と入力を教材設計の調査項目にする。日本語の語順・読み問題の単純な翻訳で完成にしない。これらの個別の教材・許容解答・音声は未作成。
5. **伝承と季節**：民俗学研究、地域の博物館、Finnish Literature Society（SKS）等から原話／異伝／現代の紹介を区別して調べる。FI04だけで全昔話を調べ尽くしたとしない。
6. **音と美術**：町と店の環境音、地域の音楽、建築・植生・服装、使えるモデル・動作・人物画。完成画面の目標を、実装した一街区で確認する。
7. **学習の支援と確認**：説明言語、音声の候補と実聴、聞き直し、意味、任意入力、保存と対象端末。現地語の台詞は校閲状況を持つ。

最初の試作は町の全部を薄く作る前に、歩いて意味が分かる一街区・一店・一つの手仕事で確かめる。ただし、これは完成作品の規模を一律に減らす決定ではない。次に作るのは地域比較と生活・言葉・動物の観察表であり、まだ架空の町の完成仕様を確定した段階ではない。
