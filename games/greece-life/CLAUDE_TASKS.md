## 3. M1：町を歩く・聞く

### 作ること
- games/greece-life/ 内に TypeScript + Vite + three.js の開発・ビルド環境。版を固定。`npm start`（ポート4175、ブラウザ自動起動）と `start-greece.cmd`。
- 三人称の主人公、WASD／矢印・Shift・右ドラッグ・E・Esc・M・Tab、カメラの壁衝突、当たり判定、扉から室内への切替。
- 5地区（Λιμάνι、Αγορά、Χώρα、Γειτονιά、Παραλία & λόφος）と、SPEC 4節の室内、賃貸候補4室。
- 島の町らしい見た目：白壁、青い扉と窓、石畳と階段、日よけ、植木鉢、カイキ、風車、礼拝堂、海。同じ箱を並べただけで景観完成としない。波・風・店の音は仮でよい。
- ギリシャ語の看板（3D、Canvas描画）と、近づくと英語訳。フォント Noto Sans を同梱。
- 会話・買い物を開く基本UI、ゲーム内時計、地図（Χάρτης）、設定（Ρυθμίσεις）。
- 72人の名簿・役割・居場所をデータに登録し、町に配置。
- `tts` モジュール（SPEC 15節）と設定画面の声の選択・試し再生。
- データ検査：全文字列が NFC、U+1F00～U+1FFF と U+037E がないこと。

### 確認
- 起動 → 自室 → 外 → 商店通り → 港 → 旧市街の広場 → 丘の風車 → 浜 → 帰宅、まで歩ける。
- カメラが建物や人の中に入り続けない。道と出入口が塞がっていない。
- 地区ごとの景色が見分けられる。
- 入力欄やメニューを開いている間、WASD が主人公を動かさない。
- 看板と最初の一言を 🔊 で再生できる（自動テストはモックで確認）。ギリシャ語の声がない場合の英語の案内が出る。
- 一枚の絵や地図上の点移動だけを M1 達成にしない。

## 4. M2：日常の一巡を遊ぶ

### 作ること
- 部屋の内見と選択、同時に一住居、引っ越し、保管箱。
- 家具40種の購入・床と壁と窓と机上の配置、回転・取消、出口と使う位置までの通路確認、バルコニー・中庭。
- 服20点と見た目への反映。
- 店の営業時間（昼休みを含む）、食材32品、すぐ食べられる品、家具・服・道具の売買、数量・価格・所持品の一括処理。
- 料理12品（r12 は M3）の材料・工程・手操作・完成品。完成品を材料に使う料理（r05）。
- 仕事：喫茶店（客4人）、パン屋（客4人）、タベルナ（2～3卓）。報酬と時間の一回加算。
- スマホの配達一覧、最大3件、集荷と配達、期限・遅配・取消、ギリシャ語の住所と地図の目印。
- 全72人に、その人だけの話題一つ、返答2～3個、短い反応。町で会える。
- 日付と営業時間、睡眠・待つ、月の家賃。
- 訳・解説の表示、🔊 再生とゆっくり再生、図鑑、任意のギリシャ語入力（画面キーボード）。
- 自動保存・再開、手動保存、JSON書き出し・読み込み・版の移行、壊れた保存の案内。
- `npm run build:standalone` で `dist/greece-life.html` を作る。

### 一巡の合格条件
1. 初めて起動し、4つの部屋を内見して一つ選ぶ。
2. 歩いて食材を買い、別の店や人に立ち寄る。店では `Καλημέρα` → 注文 → `Πόσο κάνει;` → `Ευχαριστώ` の流れが選択肢で進む。
3. 喫茶店で働く。σκέτο／μέτριο／γλυκό と εδώ／πακέτο を聞き分けて作り、渡せる。終了時刻と報酬が一度だけ変わる。
4. パン屋かタベルナでも働ける。
5. 配達を二件受け、集荷・順路を選んで届ける。持っていない荷物は渡せず、二重報酬もない。
6. 家具を買い、自室で置き、回転・保管・取消を使う。植木鉢をバルコニーか中庭に置ける（h02・h04）。
7. 壁の飾りと机を置き、家具のせいで飾りが勝手に消えない。出口は使える。
8. χωριάτικη σαλάτα と、別の料理一つ以上を作れる。材料不足では途中で消費しない。
9. 服を変えると主人公の見た目が変わる。
10. 寝て翌朝になる。終了して再開すると住居・配置・持ち物・お金・日時・仕事・設定が戻る。
11. 別の部屋へ引っ越しても住居は一つで、全家具が残る。
12. 72人が ID だけでなく、役割・固有の話題・居場所で違う。
13. ギリシャ語の声がなくても遊べ、その状態を聞き取り成功と記録しない。
14. `dist/greece-life.html` をダブルクリックしてブラウザで遊べる（サーバーなし）。

### M2の納品
- 動くビルド、ソース、依存の固定、起動方法3つ（README に日本語と英語で）。
- 単一HTMLの配布物と、必要なファイルの一覧。
- ブラウザでの歩行・買い物・仕事・配達・部屋・料理の画面証拠（Playwright のスクリーンショットを tests/artifacts/ に）。
- 意味のあるテスト：取引と消費・報酬の一回処理、引っ越しと家具保持、通路の確保、時間の大きな加算、保存と復元、声の選択とない場合の案内（モック）、文字の正規化。
- TESTING.md：実行したコマンドと結果、未実行とその理由。Windows 実機の音声、ギリシャ語の自然さは自動で合格にしない。
- PROGRESS.md：M1／M2 の達成・未達、M3 以降の残件。時間や規模で残った物は、動く到達点と次の具体的な作業を書く。
- 最後に `git status` で games/greece-life/ の外に変更がないことを示す。

## 5. M3：町に住み続ける内容

M2 が動いてから同じゲームを育てる。

- 72人それぞれ6本以上の通常・状況会話と、季節の反応。名前の入れ替えで水増ししない。
- 昼夜・天気（夏の μελτέμι、冬の雨）・仕事・昼休みで居場所と会話が変わる。
- 春夏秋冬の景色。CONTENT_PLAN.md 8節の行事（出典を確認してから説明文）。毎日を行事にしない。
- 行事の飾り、限定の品、短い仕事、食べ物を暮らしにつなぐ。r12 ταραμοσαλάτα の材料追加。
- 家具・服・料理を、本人のプレイの感想で追加。
- ローマ字表記の任意表示、英語の短い文法メモ、入力練習の改良。
- 仮素材を完成用へ。残すなら一覧と制限を書く。
- 必要ならタッチ操作。
