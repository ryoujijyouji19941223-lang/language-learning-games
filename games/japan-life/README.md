# 日本の暮らし（仮）／japan-life

日本を最初の舞台にする、独立した3D生活ゲーム。日本語で暮らし・料理・短い会話の自然さを本人が検証する。

2026-10-19：**v0.3.1 秋の町と店プレビュー（検証中）**。日本版の配色と田舎らしい余白を残し、塀・門・駐車区画・静止車・魚屋の軽トラ、二階建ての商店、歩行者用の道、松と刈り跡の田を追加。店内の球だけの仮商品を、魚・たこ・米袋・卵・瓶・衣服等へ置き換えました。時計・メニュー・地図の読みやすさを改修しています。

対象はSPEC v0.6／[PLAYTEST_REDESIGN](PLAYTEST_REDESIGN.md) v0.4。本人は両作品ともまだ散歩した段階で、生活の中身が受入済みという意味ではありません。店舗二階の賃貸は後続候補です。松・車・田畑は簡略モデル。Farthest Frontier相当の完成美術、役場からの新導入、連続した帰宅、路面電車・寺社・四季の完成景観は未達です。最新の進捗・検証は[PROGRESS](PROGRESS.md)／[TESTING](TESTING.md)、素材条件は[ART_DIRECTION](ART_DIRECTION.md)。

作業ブランチは`codex/japan-life-autumn-art`。mainと従来の`gh-pages`の配布物は旧版のままです。このフォルダの最新版プレビューを使ってください。

## 手元で起動する

[**秋の町と店プレビューZIPをダウンロード**](https://raw.githubusercontent.com/ryoujijyouji19941223-lang/language-learning-games/codex/japan-life-autumn-art/games/japan-life/releases/japan-life-rural-preview.zip)

最新版の作業ブランチ内に配布ZIPを置いています。[従来のv0.2.0 ZIP](https://raw.githubusercontent.com/ryoujijyouji19941223-lang/language-learning-games/gh-pages/japan-life/japan-life.zip)とは内容が違います。

PCのChrome／Edgeなど、WebGL 2対応ブラウザが必要です。単一HTMLの配布物は、プログラム・3Dライブラリ・描画素材をすべて含みます。ゲーム中の外部生成AI、APIキー、CDN、アカウント、サーバーDBは不要です。

配布ZIPを受け取った場合は、すべて解凍して **index.html** を通常のブラウザで開きます。Node.jsのインストールは不要です。チャット内やスマホのファイルプレビューでは実行できない場合があります。保存を許可しないブラウザでは通知を出し、その画面内で続けられます。設定のJSONで記録を退避できます。

直接開けない場合は、解凍先で次を実行してから、手元のブラウザで `http://localhost:4182` を開けます（Python 3が必要。Windowsは`python3`の代わりに`py -3`）。この管理環境のChromiumはfile URLを禁止しているため、直接開く方法の実行確認はできていません。通常のHTTP配信での起動と旧セーブの再開は確認済みです。

```sh
python3 -m http.server 4182 --bind 127.0.0.1
```

ソースから動かす場合は、手元のPCでNode.js 24を用意して、リポジトリ内の次のフォルダで実行します。

```sh
git fetch origin
git switch codex/japan-life-autumn-art
cd games/japan-life
npm ci
npm run dev
```

そのPCのブラウザで `http://localhost:4180` を開きます。これは手元でサーバーを起動した場合のアドレスです。クラウド内のlocalhostや内部パスは、利用者向けの公開・ダウンロードURLではありません。

```sh
npm run build       # dist/index.html と dist/japan-life.zip
npm run preview     # ビルドした内容を4181番で配信
npm test            # 状態管理の単体テスト
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser
```

別のPCでPlaywright用Chromiumを使う場合は `npx playwright install chromium` を実行し、環境変数を付けずに `npm run test:browser` を実行できます。検証した依存は Three.js **0.186.1**、Vite **8.3.4**、vite-plugin-singlefile **2.3.4**、Playwright **1.61.1**。lockfileに固定しています。

## 遊び方

- PC：WASD／矢印で歩く、Shiftで走る、右ドラッグで左右・高さの視点、E／Enterで近くを調べる、Escで戻る、Mで地図。
- タッチ：左スティックで移動、右の空いている部分をドラッグして視点、右下の「調べる」。確認UI中は移動と通常の時計を止めます。
- 最初に三室を内見し一つを選択。自分の部屋の玄関でEを押すと町へ出られます。町は実際の3D空間を移動します。地図は目印を付ける道案内で、瞬間移動はしません。
- 店の正面入口でE、入ったら中を歩いてカウンターへ近づきEで買い物・集荷・勤務。人に近づいてEで話を聞きます。大きな下中央の枠で「次へ」、任意の自動送りと停止・再聴を使います。設定で文字を150%まで拡大できます。必要な場面だけ返答を選びます。
- 食料店08〜20時、魚屋08〜16時、喫茶店09〜18時、玉子焼・家具・服店10〜19時。家具店は水曜休み。閉まっていたら手帳の「休む・待つ」から時間を進められます。
- 喫茶店は海辺（中央の坂を下った左）へ移転。勤務を始めたらカウンターの左を回り、棚のカップを取る→マシン／ポットへ置く→もう一度調べて抽出→待ってから取る→必要ならふた→トレーへ置く、と道具に近づきEで操作します。二杯は別々のカップで作ります。「ミルクを別で」は小さい容器を取って注ぎ、トレーへ。トレーを持って注文した客へ渡します。返却口で作り直せます。4客目の完了時に2時間・2,000円を一度だけ処理します。
- スマホで最大3件の配達を選びます。指定の店で仕事別の荷物を受け取り、町の指定受け取り口まで歩いて渡します。未集荷では渡せず、遅配は半額、取消は報酬なしです。地図で集荷先と届け先を別々に確認できます。
- 自宅の台所でEを押すと6品のレシピ。必要な材料をチェックして、順に工程を進めます。混ぜる・握る等の手操作の工程では3回の操作が必要です。材料は開始時に予約し、完成まで消費しません。料理は食べられます。
- 自宅の保管箱、または手帳の「部屋を整える」で家具を選びます。床はマスを選択、壁は面・横・高さを指定、カーテンは窓、小物は配置済みの机へ。半透明のモデルで確認し、回転・確定・取消・保管を使います。
- 出口・台所・ベッドや椅子の使用面への通路を塞ぐ配置は拒否します。低い机と壁飾りの判定は独立し、机を動かしても飾りを自動消去しません。プレイヤーと重なる家具を置いた場合は空いた玄関位置へ戻します。
- 服は購入と着用が別です。手帳の「着替える」で上下・靴を選ぶと、主人公の色・スカート等に反映します。
- ベッドで翌朝08:00まで睡眠。手帳で1時間待ち・最大7日先の朝まで休息もできます。配達期限を過ぎる可能性は事前表示します。月初の家賃は不足を未払いとして記録し、利息・強制退去はありません。
- 転居は案内所または手帳から内見して確定。住居は常に一つで、全家具を保管し、1,000円を一度だけ支払います。入りきらない家具も失いません。

## 保存・支援と制作記録

保存キーは **japan-life:v1**。旧版の入居・日付・財産・所有物・仕事・ラジオの記録を読み込みます。新規開始だけ端末の月日を使い、再開時に現実の日へ戻しません。旧セーブを秋へ合わせたい場合は設定の「開始日と季節」から任意で移行できます。未払い・所持金・仕事の残り時間を保ちます。別のファイルやURLで開く際はブラウザの保存領域が別になる場合があるため、旧版の設定でJSONを書き出して新しい画面へ読み込んでください。

確定した取引・報酬・調理・家具配置・転居と、移動停止や定期時点で自動保存します。設定からJSONを書き出し／読み込みでき、不正データでは現在の記録を保ちます。削除は確認欄から明示的に実行し、英語試作のキーには触れません。

60人の固有の会話データを保持し、通常は聞いて進みます。必要な意思決定と任意の返しで選択を使います。全件DRAFTです。正解のない好みの選択を採点しません。「読み」は話題の語句の読みと意味で、全文のふりがなではありません。任意の転記は端末IMEかかなの補助キーを使え、IME変換確定前のEnterでは確認しません。再聴の完了／失敗、転記、会話の選択は別の記録で、理解・学習効果の成功には換算しません。

3Dが重い場合は設定で「影を描く」をオフにできます。波音・足音は独自の仮の合成音で、初期状態はオフ。日本語音声は端末の声を使い、無い場合は理由を表示して文字で続けます。

日本を作ることは本人の決定。架空の港町「汐待町」、明石周辺を参考にすること、端末・技術・金額・時刻・人数は、制作に入れるよう作成者が補った変更可能な初期設定。実在の明石の街の忠実な再現ではない。

一つの町で、歩く、店へ入る、人と話す、買う、働く、料理する、部屋を整える暮らしを通す。住居は同時に一室。町並みと建物外装はプレイヤーが作り替えず、服・家具・壁飾りを変える。会話は固定の短い台詞と選択肢、外部生成AIとAPIキーは不要。

旧 games/english-errands/ は既存の別試作として保存し、コード・教材・セーブを上書きしない。

## 音楽とラジオ（2026-10-18追加）

v0.2.0で、追加された[SPEC §16](SPEC.md)・[初期曲の計画](CONTENT_PLAN.md)を実装。町の昼夜・店・自宅で曲が切り替わります。設定で音楽・声・環境音の音量と消音を別々に変更できます。ユーザー操作後に開始し、再生が拒否されたら「音を再生する」で再試行できます。無音でも生活は続けられます。

家具店で「卓上ラジオ」を1,800円で購入すると、自宅で手帳／設定の「自宅のラジオ」から5曲を試聴・決定・停止できます。机上に配置したラジオからも開け、保管・転居で選曲を失いません。試聴だけなら戻ると元の曲へ。読み上げ中はBGMを下げ、完了・取消・失敗で戻します。消音と選曲は再開しても維持します。

初期5曲は同梱した独自の仮ループです。完成曲の監修・音楽性・実際の聞こえ方は未確認。素材と制作方法は[ASSETS.md](ASSETS.md)を参照してください。


## 追加された画面と操作

大きい時計と季節を左上、アイコン付きの暮らしメニューを右上に表示。`M`は道路・建物・現在地と番号付きの行き先がある地図、`P`はスマホ・配達、`J`は手帳・持ち物。地図の番号か行き先を選ぶと町へ案内の印がつきます。地図から瞬間移動しません。

旧セーブの月日はそのまま保ちます。以前の4月の記録なら春の桜が表示されます。秋へ合わせたい場合は、設定の「開始日と季節」を使います（財産・期限の残りを保持）。秋の桜は赤褐色の葉、松は常緑です。新しい塀や停車車両に重なる旧位置だけ公道へ移します。住居ID・部屋寸法・家具は維持します。
