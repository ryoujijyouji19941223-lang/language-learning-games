# ギリシャの暮らし：制作仕様 v0.1

2026-10-18。対象 games/greece-life/。状態：制作着手用の仕様を準備、ゲーム実装は未着手。

## 0. 本人の決定と、変更できる初期設定

**本人の決定**
- 舞台は現代ギリシャ。日本版とは別の作品として、同じリポジトリの games/greece-life/ に作る。
- ゲーム内の文字（看板・会話・品名・店名・UIラベル）はギリシャ語。解説・訳・ヘルプは英語。
- PC（Windows）のブラウザで遊ぶ。ギリシャ語を音声で読み上げる。
- 制作はClaude Code。日本版の規模を真似る必要はなく、住民60人・部屋3・家具24・服12・料理6を下回らなければ、もっと大きく種類を増やしてよい。
- まず遊べるところまで作る。
- 設計の前提は docs/REGIONAL_LIFE_SIM_DESIGN.md の本人発言の表（賃貸一室、同時に住居一つ、町並み固定、服と家具・壁飾り、短い自然な選択会話、仕事と料理、独自の時計と季節、多くの住民）を引き継ぐ。

**制作担当の初期設定（変更可能）**
- キクラデス諸島の島の港町を参考にした架空の町「Ασπρόγιαλος（アスプロヤロス、仮）」を一つ作る。実在の島・町の忠実な再現ではない。町名が実在地名と重なると分かったら変更してよい。
- 技術・価格・時刻・人数・数量は下記の初期値。データファイルに分けて、変更理由を記録して変えられるようにする。

旧英語試作と日本版のコード・教材・保存を変更しない。全言語共通エンジンを作らない。

## 1. プレイヤーの目的と対象

自分の部屋で暮らし、町を歩き、人と話し、仕事・料理・買い物・部屋づくりを選んで過ごす。勝利画面や語学試験の合格を生活継続の条件にしない。

対象はギリシャ語の初学者〜初級者。説明言語は英語。ギリシャ語の看板・会話・品名に、英語の訳と音声を付けて、意味を確かめながら暮らせるようにする。遊べたことを学習効果の証明にしない。

## 2. 制作方式と操作

- 初期実装案：TypeScript + Vite + three.js。会話・スマホ・配置などのUIはHTML/CSS。版はlockfileで固定。
- 主対象：Windows PCの Microsoft Edge と Google Chrome。キーボード＋マウス。タッチ操作は M3 以降の任意。
- 表現：ローポリのデフォルメした人と、白壁・青い扉や窓・石畳・階段の多い島の港町。外部の3Dモデルは使わず、three.js の基本形状と自作の簡易モデルから始める。素材を入れたら作者・条件を記録する。
- 三人称で主人公を見ながら歩く。カメラの左右回転・高さ、壁際の衝突、会話中に相手が見えることを扱う。
- 必須：歩く、短く走る、衝突、扉から室内へ入る、人に近づいて話す。ジャンプ・乗り物・戦闘は不要。
- PC操作：WASD／矢印で移動、Shiftで走る、右ドラッグで視点、E／Enterで調べる・話す、Escで戻る、Mで地図、Tabで持ち物。入力欄にフォーカスがある間は移動キーを止める。
- 全画面UIで町を常に隠さない。

## 3. 起動と配布（ユーザーは操作が少ないほどよい）

- 開発：`npm start`（games/greece-life/ 内）。初回は自動で依存を入れてよい。ポートは 4175 に固定し、ブラウザを自動で開く。
- Windows用：`start-greece.cmd` をダブルクリックで同じことができるようにする。
- 配布：`npm run build:standalone` で `dist/greece-life.html` 一つにまとめ、ダブルクリックでブラウザから遊べるようにする（既存の英語試作と同じ考え方）。一つにまとめられない部分があれば理由と代わりの手順を書く。
- オプションやフラグを増やさない。起動方法は上の3つだけにする。
- localhost やクラウド内のパスを、利用者が遊べるURLとして案内しない。

## 4. 町の構成

一つの町の中に五つの地区をつなぐ。地区の間は実際に歩いて移動する。室内への切替ロードは可。地図からの瞬間移動だけで歩くことを代替しない。

| Αγορά（商店通り） | 店先、日よけ、木箱の野菜、看板 | φούρνος、καφετέρια、μανάβικο、μίνι μάρκετ、σουβλατζίδικο、ζαχαροπλαστείο、χασάπικο、τυροπωλείο、家具店、服店、花屋、雑貨店。毎週土曜は通りに λαϊκή が立つ |
| Χώρα（旧市街と広場） | 白壁の細い路地、階段、ブーゲンビリア、広場とプラタナス | καφενείο、教会、郵便局、役場の窓口、薬局、床屋、本屋、民宿 |

- 町の端から端まで、走らず4～6分程度（調整目標）。
- 主人公が入って歩ける室内：自宅、καφετέρια、φούρνος、ταβέρνα、μίνι μάρκετ、家具店、服店、καφενείο。他の店は店先のカウンターで買い物してよい。
- プレイヤーは道・建物・外装を変えない。季節・行事の飾りは制作側が暦で変える。
- 看板はギリシャ語。大文字の看板は原則アクセントなし（例：ΦΟΥΡΝΟΣ）。近づくと英語訳を出せる。

## 5. 一巡の流れ

部屋を内見して選ぶ → 外へ出る → 人に話しかける → 食材を買う → 仕事をして稼ぐ → 配達する → 家具を買う → 帰って置く → 料理して食べる → 眠る → 保存して翌日再開。

導入は任意にスキップできる。順番・仕事・買う物はプレイヤーが選ぶ。矢印で答えだけを追わせない。

## 6. 住居は同時に一つ

床は0.5m＝1マス（ゲーム用）。家賃はゲーム内の値で、実際のギリシャの相場ではない。

| ID | 場所 | 主室 | 特徴 | 月の家賃 |
|---|---|---|---|---:|
| h01 | Γειτονιά | 6×8 | 小さな台所、窓1 | 220 € |
| h02 | Γειτονιά | 8×8 | 海が見えるバルコニー（4×2）付き、窓1 | 300 € |
| h03 | Αγορά | 8×10 | 店の2階、窓2、店に近い | 340 € |
| h04 | Χώρα | 10×10 | 古い家の一室、小さな中庭（4×4）付き、窓2 | 420 € |

- 新規開始時：初月の家賃は支払済み、所持金 150 €。ベッド・机・椅子・台所設備・最低限の調味料あり。
- 内見は自由。契約は現在の一室だけ。
- 引っ越し費 20 €。確定時に全家具を保管箱へ移し、新居へ切り替える。失敗したら前の状態を保つ。保管箱は容量制限なし。家具を捨てない。
- 家賃は毎月1日に一回だけ引く。不足は「あとで払う額」として記録。利息・退去はなし。実際の賃貸制度として解説しない。
- バルコニー・中庭は「植木鉢と屋外家具だけ置ける床」として扱う。建物の外装は変えない。

## 7. 家具と壁飾り

- 床の家具は占有マス、90度回転、移動、保管、取消。
- 入口から部屋の中、ベッド・台所の使う位置までの通路を保つ。出口を塞ぐ配置は確定しない。
- 壁は面ごとのマス。鏡・時計・絵・棚・お守りなどを置く。窓にはカーテン。壁紙・床材・天井は変えない。
- 本人の「机を壁際に置くと壁判定が消える」の意味は未確定（docs/REGIONAL_LIFE_SIM_DESIGN.md 3.2）。床と壁は別判定にし、机を置いたせいで壁飾りを勝手に消さない。壁が主人公を隠すときの透け表示は表示上の機能として別にする。
- 机の上の小物は専用の置き場所（アンカー）に置く。
- 全家具に形が分かる3Dモデルを付ける。アイコンだけで終わらない。
- 全件は CONTENT_PLAN.md。

## 8. 服

上・下・靴・小物の4枠。所有と着用を分け、主人公の見た目に反映する。全件は CONTENT_PLAN.md。

## 9. 時計と暦

- 現実と同期しない。閉じている間・タブ非表示中は進めない。
- 初期の暦：1年目 5月1日（Πρωτομαγιά）08:00 開始。通常の12か月、2月は28日、月曜始まり。実在の年の暦として表示しない。
- 季節：3～5月春、6～8月夏、9～11月秋、12～2月冬。冬は雪なし、雨と風が多め。夏（特に8月）は強い北風（μελτέμι）の日がある。
- 歩いている間：現実1秒でゲーム内30秒（24時間＝現実48分）。
- 会話・訳の確認・家具編集・設定・商品を見ている間は止まる。買う・作る・働くを確定したら、その行動の時間を一回だけ足す。
- ベッドで翌朝08:00へ。ベンチで1時間待つ。カレンダーから最大7日先まで休める（期限付きの仕事があれば事前に表示）。
- 0時の日付・家賃、営業時間、行事の開始終了は、大きく時間を進めても順番に処理する。
- 昼の休み時間：多くの小さな店は平日の昼過ぎ（目安 14:30～17:30）に閉まり、火・木・金は夕方に再開する（ゲーム用の簡略化。CONTENT_PLAN.md に店ごとの表）。この時間は住民が家にいて静か、という雰囲気を出す。
- 行事は CONTENT_PLAN.md。実在の祝日は出典を確認してから説明文を付ける。移動祝日（Πάσχα など）はゲーム暦で固定日にしたことを明記する。

## 10. お金と買い物

- 通貨はユーロ。内部はセント単位の整数で持つ。表示はギリシャ式（`3,50 €`、`Intl.NumberFormat('el-GR', {style:'currency', currency:'EUR'})`）。
- 商品は価格・在庫・分類・買える店・所持数をデータで持つ。支払い・在庫・所持品は一回でまとめて変える。足りないときに途中まで消費しない。
- 店の会話：入店で `Καλημέρα!` / `Καλησπέρα!`、注文は `Θα ήθελα…`、値段は `Πόσο κάνει;`、支払いで `Ορίστε.`、最後に `Ευχαριστώ!`。選択肢で進められる。
- 食料は初期版で腐らない。料理は食べるか住民への贈り物に使う。自宅料理の無限転売はしない。
- 生活が仕事だけにならないよう、家賃・報酬・価格は一緒に調整する。

## 11. 仕事

全部の仕事を同じ文字入力問題にしない。聞く・読む・選ぶ・運ぶ・渡すを組み合わせる。報酬と時間は一回だけ加算。途中で中断しても再開できる。失敗で解雇や大きな罰はなし。客が短く確認し直して先へ進める。

| 仕事 | 場所 | 時間 | 報酬 | 遊び方 |
|---|---|---|---:|---|
| 喫茶店 | καφετέρια | 2時間 | 18 € | 客4人。飲み物（φρέντο εσπρέσο / φρέντο καπουτσίνο / φραπέ / ελληνικός καφές）、砂糖（σκέτο / μέτριο / γλυκό）、店内か持ち帰り（εδώ / πακέτο）を聞いて作って渡す |
| パン屋 | φούρνος | 朝06:00～08:00 | 16 €＋κουλούρι 1 | 焼き上がりを棚へ並べ、客4人の注文（品と数）を袋に入れて渡す |
| タベルナ | ταβέρνα | 夜19:00～22:00 | 28 € | 2～3卓の注文を聞き、厨房から料理を運ぶ。水とパンを先に出す習慣を入れる |
| 配達 | 集荷場・店 | 期限まで | 4 / 6 / 8 € | スマホの一覧から受ける。最大3件同時。期限は受けてからゲーム内90/120/180分 |

- 配達：受ける → 店で荷物を受け取る → 歩いて届け先へ → 渡す → 報酬。荷物は仕事IDで区別し、食材と混ぜない。二重報酬なし。遅れたら半額で完了。取消は報酬なしで罰なし。届け先の住所はギリシャ語（例：`Οδός Ανέμων 5`）で、地図と目印で探せる。
- 住民のお願い：買ってきて・届けて・探して。受ける・断る・今は無理、を選べる。雑談を全部お願いにしない。

## 12. 料理

- 店で材料を買い、自宅の台所でレシピと所持数を確認、材料を選ぶ → 工程を順に操作 → 完成。文字入力だけで代わりにしない。
- 材料は開始時に予約、完成時に消費と完成品追加を一回で確定。途中で失敗しても未確定の材料を失わない。
- 初期13品と材料は CONTENT_PLAN.md。数量・時間はゲーム用の簡略化で、実用レシピとして表示しない。主な材料と特色は出典と矛盾させない。χωριάτικη σαλάτα にレタスを入れない。

## 13. 人と会話

- 会話できる住民 72人。名簿は CONTENT_PLAN.md。背景の通行人は人数に数えない。
- 住民ごとに家または定位置、仕事、朝昼夕夜の居場所、興味、口調、外見の違い（服の色・髪・体形・小物）を持つ。
- M2：全72人に最低一つ、その人だけの話題と、返答2～3個、短い相手の反応。M3：各人6本以上の通常・状況会話と季節の差分。
- 好み・共感・苦手などの返答はどれも正解。語学の正誤問題にしない。一往復で終わってよい。
- 呼び方：店員と客の最初はていねい（`σας`）、顔見知り・同年代はくだけた形（`σου`）。全員を同じ調子にしない。
- 会話データは別ファイル。各行に NPC ID、意図、条件、ギリシャ語本文、英語訳、読み上げ用テキストを持つ。
- 外部生成AI・APIキー・自由会話サーバーは使わない。

## 14. 言葉の支援（英語で解説）

- 会話・看板・品物を調べると、英語訳、短い英語の解説（例：`σκέτο = no sugar`）、🔊 再生、ゆっくり再生ができる。
- 「訳を常に表示」「必要なときだけ表示」を設定で選べる。
- 図鑑（Λεξικό）に見た言葉を残し、お気に入りにできる。同じ言葉を買い物・仕事・料理・道案内で使い回す。
- ローマ字表記（ラテン文字への転写）は M3 の任意機能。入れる場合は方式（例：ELOT 743）を明記する。
- 任意の入力練習：ギリシャ語キーボードの画面版（標準配列、アクセント記号 ΄、語末の ς）。WindowsのOS側のギリシャ語キーボードでも入力できる。入力しなくても生活は進む。アクセントの有無を許すかは項目ごとに決め、許した場合は「支援あり」と記録する。
- 読む・選ぶ・写す・自分で思い出して入力する、を別々に記録する。正解率で町や家具を開放しない。

## 15. ギリシャ語の音声（必須）

- ブラウザ標準の Web Speech API（`speechSynthesis`）を使う。外部の有料音声サービスは使わない。
- `lang` が `el` で始まる声を探し、名前に Athina → Nestoras → Stefanos を含む声の順に選ぶ。なければ最初の `el` の声。
- `getVoices()` は最初に空のことがある。`voiceschanged` を待ち、3秒でタイムアウト。Edge のオンライン音声は後から届くので、一覧は更新し続ける。
- `speak()` はクリックなどの操作の中だけで呼ぶ。1回に読むのは短い1行。再生前に前の音声を止める。`utterance.lang` も設定する。
- 設定画面：声の選択、音声オン／オフ、速さ（通常1.0／ゆっくり0.8）、試し再生、使用中の声の名前。
- ギリシャ語の声がない場合：文字で遊べるまま、英語で案内を出す（Edge で開く、または Windows 設定 › 時刻と言語 › 音声 › 音声を追加 で Greek を追加してブラウザを再起動）。ゲームは止めない。この状態を聞き取り成功として記録しない。
- 推奨ブラウザは Edge（追加の設定なしでギリシャ語の声が使える見込み。実機確認は残る）。
- 実装の例と根拠は RESEARCH.md。

## 16. 文字とフォント

- ソースは UTF-8。全文字列を NFC で保存・比較する。
- アクセントは現代の単一アクセント（tonos、U+0386～U+03CE の範囲）。古代ギリシャ語用の拡張文字（U+1F00～U+1FFF）を使わない。ギリシャ語の疑問符は通常の `;` を使い、U+037E を使わない。
- 語末のシグマは `ς`。
- フォントは Noto Sans（latin＋greek サブセット、OFL）を作品内に同梱し、オフラインでも表示する。3D看板を Canvas に描く前に `document.fonts.load()` で読み込みを待つ。
- `<html lang="el">`。英語の訳・解説の要素には `lang="en"`。

## 17. 保存と復帰

- キーは `greece-life:v1`。他の作品のキーに触れない。
- 保存する物：版、時計と暦、所持金、家賃の処理日、現在の住居、家具の所有と配置、服、食材、料理、住民との履歴、仕事と途中状態、図鑑、設定（音声含む）。
- 買う・引っ越し・報酬・料理の確定で自動保存。ベッドで寝ると保存。手動の保存（Αποθήκευση）と読み込み（Φόρτωση）も置く。
- JSONの書き出し・読み込み、版と範囲の検証、壊れたデータの案内と安全な初期化、明示的な削除。
- 保存できないときは知らせて、その場では遊び続けられる。復帰で報酬・材料・家賃を二重に処理しない。
- 最初は localStorage。足りなくなったら IndexedDB へ移す。
