# ことばの小さなおつかい（仮）

英語のお願いを聞き、3つの絵から品物を選んで、名前を荷札に書くブラウザゲームです。[制作仕様](SPEC.md) に沿った遊べる初期試作 v0.1.0 を実装しました。

## 起動

ゲームのZIPとGitHub Pagesの公開設定は [配信手順](PUBLISHING.md) を参照してください。クラウド内のファイルパスをチャットへ貼っても、利用者向けのダウンロードURLにはなりません。

### サーバーを立てずに遊ぶ

`dist/english-errands.html` は画像・プログラムを1つにまとめたHTMLです。このファイルをPCに保存し、ChromeやEdgeなどのブラウザで開いてください。Node.jsのインストールやコマンドの実行は不要です。チャット内やスマホのファイルプレビューではJavaScriptが実行されない場合があるので、通常のブラウザを使ってください。

開発者が単一HTMLを再生成する場合だけ、次を実行します（追加依存なし）。

```sh
npm run build:standalone
```

### ソースから開発サーバーを起動する

Node.js 24（検証済み）があれば、ゲームを遊ぶための依存インストール・ビルド・APIキーは不要です。

```sh
cd /workspace/language-learning-games/games/english-errands
npm start
```

ポート4173で起動します。ローカルPCではブラウザのアドレス欄に `http://localhost:4173` を入力してください。このクラウドのオンボーディング画面には開発サーバーのプレビュー機能がなく、クラウド内でサーバーを動かすだけでは手元のブラウザで遊べません。手元でサーバーを起動するか、上の単一HTML版を使います。ソースの `index.html` は分割されたmodulesを読み込むので、単一HTML版と違いHTTP配信が必要です。

ポートや待受先を変える場合は `PORT=8080 HOST=127.0.0.1 npm start` のように指定できます。終了は Ctrl+C。保存先はブラウザのオリジン単位なので、ポートやホストを変えると以前の記録は自動では移りません。設定画面のJSONで移せます。

## 遊び方

1. 「おつかいをはじめる」で、その組の4語の絵・意味・単語・お願いを確認します。単語とお願いの音声を再生できます。既習ならスキップできます。
2. お客さんの英語を聞き、3候補から品物を選びます。「英文を見る」「意味を見る」はいつでも使えます。2回間違うと正しい品物と名前を確認して進みます。
3. 英語1語の名前を入力して「決定」。物理キーまたは画面QWERTYを使えます。「お手本を見る」で次の文字とキーが光ります。誤答時は再入力か「今回は確認して渡す」を選べます。
4. 「お客さんに渡す」のあとにお願いの英文・意味を確認できます。任意の「この文も打つ」は単語想起とは別の転記記録です。コンマ・最後の点は省略できます。
5. 6件完了で店先の飾りが1つ増え、次の組が開きます。3組のあとには12語の混合になります。正解率や速度は開放条件にしません。

時間制限・ゲームオーバーはありません。お手本を使いながら全件完了できます。図鑑は12語・24画像、お気に入り、単語・お願い音声、確認した状態と成績を表示します。

## 記録と音声

- 進行・設定・お気に入り・途中入力は自動保存します。タイトルの「つづきから届ける」で再開します。完成した試行の入力全文は履歴に残しません。
- 保存キーは `little-word-shop:english-errands:v1`。版と作品IDを検証し、壊れた保存でも起動できます。保存不可なら通知し、その画面内では遊べます。JSON書き出しで退避できます。
- 設定でJSONを書き出し／読み込みできます。読み込みはこの作品の記録を置き換え、不正データなら現在の記録を保ちます。削除は確認欄を開いて明示的に実行し、この作品のキーだけを削除します。
- 聞き取り初回成功、お手本なしの綴り初回成功、支援を使った配達、文の転記を別々に集計します。支援を閉じても使用履歴は消えません。自動補正の使用状況は `unknown` のままとし、未使用とは推測しません。
- ブラウザの英語音声合成を使います。英語の声、音声オン／オフ、自動再生、通常1.0／ゆっくり0.8を設定できます。再生前・次問・画面移動では前の音声を停止します。
- 音声が使えない場合は理由と再試行手段を表示し、英文で遊べます。その試行を音だけの聞き取り成功にはしません。英語の声が後から読み込まれた場合にも対応します。
- 端末の声の有無・品質やオフライン音声を保証しません。ゲームから外部生成AIへの通信はありません。音声自体のネットワーク利用は端末の音声エンジンに依存します。

## 検証

```sh
cd /workspace/language-learning-games/games/english-errands
npm ci --cache /tmp/english-errands-npm
npm test
# 初回：Playwright管理のChromiumを用意する場合
npx playwright install chromium
npm run test:browser
```

システムのChromiumがある環境では、ダウンロードの代わりに次のコマンドを使えます。このクラウドで実行した方法です。

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:browser
```

詳細な検証結果・実機未確認点は [TESTING.md](TESTING.md)。変更は [CHANGELOG.md](CHANGELOG.md)、素材の作者・利用条件・加工は [assets/README.md](assets/README.md) に記録しています。

## ファイル

| 場所                       | 内容                                             |
| -------------------------- | ------------------------------------------------ |
| `index.html` / `style.css` | 日本語UI、PC・360px対応画面                      |
| `src/data.js`              | SPECの12語・依頼・訳、画像と音声参照             |
| `src/engine.js`            | 出題、判定、支援、状態遷移、完了と報酬           |
| `src/storage.js`           | 保存形式の検証とlocalStorage入出力               |
| `src/speech.js`            | 英語音声・停止・失敗処理                         |
| `src/app.js`               | 画面、物理／画面入力、設定、記録の移行           |
| `assets/`                  | 独自SVG：24点の品物とキツネ1点                   |
| `tests/`                   | 判定・保存・出題・音声の単体テストとブラウザ操作 |
| `server.mjs`               | Node.js標準ライブラリだけの開発用HTTPサーバー    |

技術はHTML/CSS/JavaScript modules。実行時の外部ライブラリ・CDN・共通ゲーム基盤・アカウント・サーバーDBはありません。開発用依存は固定版のPlaywrightです。
